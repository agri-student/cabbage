# 🥬 栽培日記（キャベツ・ブロッコリー・カリフラワー）

生徒たちのキャベツ・ブロッコリー・カリフラワー栽培のようすを集めた、**フォトギャラリー付きのホームページ**です。
3つの野菜を1つのページにまとめ、栽培カレンダーは野菜ごとに切り替えて見られます。

HTML / CSS / JavaScript だけで作られているので、**サーバーは不要**。
`index.html` をブラウザで開くだけで表示できます。

---

## 📄 ページの内容

| セクション | 内容 |
| --- | --- |
| どんな野菜？ | 3つの野菜がアブラナ科の同じ仲間であることをやさしく紹介 |
| 育てた品種 | キャベツ「初秋」／ブロッコリー「ピクセル」／カリフラワー「スノークラウン」「オレンジブーケ」の特徴 |
| フォトギャラリー | 栽培写真を一覧表示（作業で絞り込み・クリックで拡大） |
| 栽培カレンダー | 定植から収穫までの実習の記録（野菜ごとにタブで切り替え） |
| 豆知識 | 知って楽しいアブラナ科野菜のひみつ |
| 生徒の声 | 育てた生徒たちのコメント |

---

## ✏️ まだ書いていないところ（「未記入」と表示されている欄）

点線の下線がついた「未記入」の文字は、あとで書き換える場所です。すべて `index.html` にあります。

| 欄 | 探し方 |
| --- | --- |
| 栽培カレンダーの日付・作業内容 | `id="cal-cabbage"` / `id="cal-broccoli"` / `id="cal-cauliflower"` 内の「日付：未記入」「作業内容：未記入」 |
| 生徒の声 | `id="voice"` のセクション内の「感想：未記入」「学年・名前：未記入」 |

書き換えるときは `<span class="blank">…</span>` ごと消して、文字だけにしてください。
（例：`<span class="blank">日付：未記入</span>` → `9月10日`）

---

## 📷 写真を追加・変更するには

`images/` フォルダに画像を入れ、`js/gallery-data.js` の一覧に次の3つを書き足します。

| 項目 | 書くこと |
| --- | --- |
| `src` | ファイル名（例 `images/cabbage-ueru01.jpg`） |
| `caption` | 写真の説明 |
| `category` | 作業：`seed`（定植）/ `care`（お世話）/ `grow`（育つ様子）/ `harvest`（収穫・試食） |

---

## 🎨 文章やデザインを変えたいとき

| 変えたいもの | 編集するファイル |
| --- | --- |
| 見出し・説明文・豆知識などの文章 | `index.html` |
| 色や見た目 | `css/style.css`（上の方の `:root` で色をまとめて変更できます） |
| ギャラリーの写真 | `js/gallery-data.js` |

---

## 📁 ファイル構成

```
cabbage/
├── index.html            … ページ本体
├── css/
│   └── style.css         … デザイン
├── js/
│   ├── gallery-data.js   … ギャラリーの写真リスト（ここを編集）
│   └── main.js           … ギャラリー・拡大表示・カレンダー切り替えの動き
├── images/               … 写真・イラストを入れる場所
│   └── icon-〇〇.svg      … 野菜のアイコン
└── README.md             … この説明ファイル
```

---

## 🌐 インターネットに公開するには

GitHub Pages を使うと無料で公開できます。

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にする
3. Branch を公開したいブランチ（例 `main`）／`/root` に設定して保存
4. 数分待つと表示される URL でホームページが公開されます
